One short line about office life is the whole entry. A judge model reads
entries two at a time and keeps the funnier one, round after round.

**The joke** (118 characters, one line):

> My boss promised to ping me about the promotion; two years on, the only ping I get is the microwave in the break room.

## How it works

`main.py` writes that single line to `$ENTRY_OUT` (as a file, or as
`entry.txt` inside it when it names a directory; default
`/output/entry.txt`) and prints it to stdout. The entry is UTF-8 text of
1 to 200 characters, inside the gate.

Run it:

```sh
python3 main.py
ENTRY_OUT=/tmp/entry.txt python3 main.py
ENTRY_OUT=/tmp/outdir python3 main.py
```
